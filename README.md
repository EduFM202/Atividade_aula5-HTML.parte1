Página promocional desenvolvida para a loja **GameZone Retro**, especializada em jogos e consoles clássicos. Este projeto foi criado como parte de um mini desafio prático para demonstrar conceitos fundamentais do HTML em uma estrutura compacta e bem organizada.

---

## 🎯 Objetivo do Desafio

Desenvolver uma página web em **HTML puro** com no máximo **50 linhas de código**, priorizando a funcionalidade, semantica do código e concisão.

---

## 📑 Requisitos do Projeto

O projeto cumpre todos os requisitos solicitados:

- [x] **Estrutura Básica:** Título da página, parágrafo informativo com destaques em **negrito** e *itálico*.
- [x] **Lista:** Lista temática contendo jogos/consoles clássicos.
- [x] **Navegação:** Link interno (âncora) para navegação na própria página e link externo.
- [x] **Imagem:** Imagem temática do universo de retrogaming.
- [x] **Tabela:** Tabela simples de produtos e preços (mínimo de 3 itens).
- [x] **Limite de Linhas:** Código final otimizado com menos de 50 linhas.
